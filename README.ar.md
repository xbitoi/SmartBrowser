# المتصفح الذكي — SmartBrowser

متصفح ذكي وتطبيق شامل يعمل على iOS واندرويد والويب، مبني بـ React Native و Expo. تصفح بالتبويبات مع تسجيل دخول واعدادات ومزامنة سحابية ومدفوعات وخرائط ووسائط.

## المميزات

- 🌐 تصفح ذكي بالتبويبات (WebView) مع الاعدادات والسجل
- 👤 تسجيل دخول واعدادات المستخدم مع مزامنة سحابية (Supabase)
- 💳 مدفوعات داخل التطبيق (Stripe)
- 🗺️ خرائط وموقع وكاميرا واختيار صور ومكتبة وسائط
- 🔔 اشعارات فورية ومعلومات الجهاز وتخزين امن وبصمة
- 📊 رسوم بيانية وتقويم وماركداون و QR ومشاركة ملفات
- 🎨 واجهة عصرية: Paper و Reanimated و Skia وقوائم سفلية
- 🔐 تشفير طرف لطرف + GraphQL وادارة حالة Redux/Zustand

## التشغيل محليا

المتطلبات: Node.js و Expo CLI ومحاكي اندرويد او Xcode.

```bash
npm install
npm run start     # خادم تطوير Expo
npm run android   # محاكي اندرويد
npm run ios       # محاكي iOS
npm run web       # نسخة الويب
npm run lint      # فحص الكود
```

## التقنيات

Expo 53 و React Native 0.79 و React 19 و expo-router و TypeScript و Supabase و Stripe.
